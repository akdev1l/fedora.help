# {{ brand }} : Faites de Fedora la Vôtre

{{ brandlink() }} est un guide communautaire non officiel consacré aux
logiciels que Fedora ne peut pas distribuer : codecs multimédias, pilote
NVIDIA, dépôts tiers comme RPM Fusion et Flathub, et les applications
propriétaires dont la plupart des bureaux finissent par avoir besoin. Plus les
correctifs qu'une installation fraîche réclame généralement.

## Pourquoi ce site existe

Fedora ne distribue que des logiciels libres et open source, conformément à la
[mission du projet Fedora][mission]. La position juridique de Red Hat exclut en
outre le code couvert par des brevets ou soumis à des restrictions de
redistribution. Un certain nombre de choses que les utilisateurs de bureau
tiennent pour acquises ne peuvent donc pas se trouver dans Fedora :

- Codecs multimédias brevetés (H.264, HEVC, AAC et consorts)
- Le pilote propriétaire NVIDIA
- Micrologiciels propriétaires et blobs de prise en charge matérielle
- Applications à code fermé : Steam, Discord, Chrome, Spotify

Cela sort du périmètre du projet, la documentation doit donc vivre ailleurs.

## À qui cela s'adresse

Les utilisateurs de Fedora en environnement de bureau qui veulent que les
composants propriétaires fonctionnent, et qui veulent comprendre ce qu'ils ont
installé une fois que c'est fait.

Les guides supposent un lecteur qui :

- sait ouvrir un terminal et travailler dans un interpréteur de commandes
- n'a pas peur d'exécuter des commandes, y compris en root
- lit une commande avant de la coller
- veut se constituer ses propres connaissances de Fedora en chemin

Ils visent les versions de Fedora actuellement prises en charge sur x86_64 :
Workstation et les spins de bureau. Les variantes atomiques (Silverblue,
Kinoite) sont signalées là où les étapes diffèrent.

Rien de tout cela n'est obligatoire. Une installation Fedora standard est
complète et prise en charge telle quelle ; chaque page ici en sort.
